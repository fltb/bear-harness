# Asset provenance

The PNG character master, damaged-signal CG, and animated WebP were generated for this repository with OpenAI image generation on 2026-08-16. The twelve full-body RGBA expression sprites and separately cropped avatar were generated or derived from that project-owned character master on 2026-08-17. The animated WebP is a locally encoded motion treatment derived from the generated damaged-signal CG. They are original project assets and do not copy Monika After Story, Ren'Py games, or existing character IP.

The Aurora Study and Snowfield Camp PNG backgrounds were generated for this repository with OpenAI image generation on 2026-08-17. They use the character master and damaged-signal CG as project-owned style references. The superseded SVG backgrounds remain as project source history and are not referenced by the role package.

The following production assets were generated for this repository with the built-in OpenAI image generation tool on 2026-08-29, using the project-owned Aurora Study and damaged-signal CG only as visual-world, material, and character references:

- Scene backgrounds: `scene-quiet-terminal.webp`, `scene-archive-gallery.webp`, `scene-relay-room.webp`, `scene-coastal-beacon.webp`, `scene-last-shift-room.webp`, `scene-future-beacon.webp`, and `scene-study-dawn.webp`.
- Story CGs: `cg-storm-relay-map.webp`, `cg-snow-route.webp`, `cg-two-handoffs.webp`, `cg-last-shift-desk.webp`, `cg-future-beacon.webp`, and `cg-returned-lamp.webp`.
- Companion continuity CG: `cg-continuity-light.webp`, generated as a separate handover-lamp image so the continuity Skill does not reuse or imply the damaged-signal story.

The generation prompts required the established weathered polar-station realism, deep teal/charcoal/amber palette, wide uncropped evidence compositions, no readable text or third-party marks, and explicit evidence boundaries. In particular, the relay CG preserves two unresolved paths, the snow CG separates confirmed and inferred movement, the handoff CG gives both sources equal weight, the last-shift CG leaves receipt unconfirmed, the future CG is visibly hypothetical, and the returned ending does not depict successful delivery.

The repository copies are high-quality WebP derivatives encoded from the generated PNG sources to keep the complete importable character package below the Host's 25 MiB safety limit. The original generated PNGs remain in the local ImageGen output directory recorded by the generation session.

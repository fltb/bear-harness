# 白熊客栈 / Bear Harness

## 产品名称

- 中文名：白熊客栈
- 英文名：Bear Harness

两个名称指向同一个产品。面向中文用户的界面、产品介绍和传播材料使用“白熊客栈”；英文界面、仓库和工程语境使用“Bear Harness”。

## 产品定位

白熊客栈是一个本地 AI 角色扮演平台。它承载角色包、对话、关系、世界设定和经用户确认的现实工作。Host 管理状态、权限、上下文与执行记录；角色包定义人物、语气、设定、场景和可选的叙事机制。

极昼是随产品交付的默认角色包，提供一种具体的相处方式和故事入口。用户可以进入极昼，也可以使用其他角色包；平台不以任何单一角色定义自身。

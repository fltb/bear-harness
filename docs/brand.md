# 白熊客栈 / Bear Harness 品牌

## 产品与角色

Bear Harness 是框架和桌面产品；极昼（Jizhou）是默认角色包。产品名、app id、可执行文件、更新策略和默认角色 selector 属于 `@bear-harness/product-config`；角色名字、个性、故事、场景、素材与角色 UI 文案属于 `characters/<companionId>/`。

Fork 可以替换产品身份和默认角色，但必须一起修改配置、资产、许可证归属和包验证，不能只改可见名称。

# Bear Harness 1.0.2

Provider-native web search support.

- Expose `web_search` only for recognized models and official provider endpoints that support the adapted native search protocol; hide it for unsupported models.
- Update the available search tool when the conversation model changes, without changing other active tools or Pi-owned conversation state.
- Adapt native search responses from OpenAI, Codex, Anthropic, DeepSeek, Gemini, and xAI into ordinary Pi tool results with answers and source links.
- Keep provider credentials in the existing credential store. No separate search-service account or API key is required.

Search availability still depends on the provider account and model. Search answers and source relevance are model-generated and are not independently verified by Bear. Protocol coverage and live-smoke limitations are documented in `docs/native-web-search-protocol.md`.

This change does not alter character prompts or memory policy. These notes prepare the version; they do not assert completion of release gates or publication.

# 主对话完整行为验收矩阵与执行报告

更新时间：2026-09-07
状态：**本轮可执行门禁已完成；发布范围外与外部设备项明确列出**

## 1. 目标与边界

本矩阵用于验收 Bear 主对话路径从用户输入、Pi 处理、流式投影、富内容展示、消息操作、会话切换、恢复，到工具/媒体/结果联动的完整行为。验收必须同时证明“看起来正确”“交互正确”“权威边界正确”“异常时仍正确”，不能只凭最终截图或最终 settled 状态判断通过。

本轮包含：

- 新建、打开、刷新和切换对话；
- Composer、发送、排队、停止、失败、编辑、重生成、分支与复制；
- 稳定消息、流式消息、Markdown、代码、公式、工具、Choices、Media、Run 和 Artifact；
- 滚动保护、响应式布局、动效、触控、键盘与无障碍；
- 多会话并发、模型隔离、恢复、协议隔离、路径安全和资源释放；
- 真实模型的自然对话、角色剧情、CG/场景/表情选择和自然富内容输出；
- WebDev 能证明的主路径，以及必须留给 Electron、真实设备、辅助技术和发布流水线的外部验收项。

本轮不包含系统设置页和角色设置页的视觉美化；但会验证主路径依赖设置结果时的只读表现，例如 Composer 中的模型标签。不会用设置页来绕过或替代主对话验收。

## 2. 不可妥协的产品不变量

| ID | 行为不变量 | 通过标准 |
| --- | --- | --- |
| INV-01 | Pi 是消息、分支、模型历史、运行与流式状态的唯一权威 | UI 不持久化第二份 transcript，不自行推断 settled，不以 UI 标志替代 Pi 状态 |
| INV-02 | `MessageContent` 只是展示层 | 只消费上层响应式文本/状态；无消息缓存、会话状态、网络请求或持久化写入 |
| INV-03 | 每个事件显式属于一个 `conversationId` | 任意切换、并发和迟到事件都不能污染其他会话 |
| INV-04 | UI active 仅是当前窗口的本地选择 | 切换 active 不停止、重路由或处置后台会话 |
| INV-05 | 乐观状态只能短暂补足用户操作反馈 | 权威 user entry 到达即交接；第一段 assistant 输出出现时不得仍显示“发送中” |
| INV-06 | 重连以权威快照替换投影 | 暂态事件不是第二份可重放 transcript；请求快照期间到达的实时事件不得丢失 |
| INV-07 | Choices、Media、工具和 Artifact 保持原领域归属 | Markdown 不能伪造按钮或 Host 命令；预览不改变对象所有权 |
| INV-08 | Renderer 不提供权威文件路径 | 文件、Media、Artifact 操作只接受受约束 ID 或普通自然语言文本 |
| INV-09 | UI 临时资源有明确生命周期 | Observer、listener、timer、剪贴板反馈、滚动位置和操作缓存卸载后释放 |
| INV-10 | 测试证据不得掩盖真实行为 | 不用禁用动画的快照证明动效；不以真实模型随机输出证明解析安全；不以单元测试代替实际点击 |

## 4. 固定内容与故障样本

1. 短中文、长中文、英文、中文与英文混排、Emoji、组合音标、RTL 片段。
2. 1、2、6、8、20、100 行输入；首尾空白；只有换行；超长不可断字符串。
3. Markdown：六级标题、强调、删除线、嵌套列表、引用、链接、分隔线、表格、任务列表。
4. 代码：有/无语言、未知语言、空代码块、HTML 字符、超长行、长代码块、多代码块。
5. 公式：行内、块级、连续公式、非法 LaTeX、未闭合定界符、安全敏感命令。
6. 流式切片：在强调、行内代码、围栏、链接、表格行、公式定界符中间逐一切断。
7. 安全：原始 HTML、事件属性、`javascript:`、data URL、远程 Markdown 图片、畸形 URL、深层嵌套、超大输入。
8. 故障：首 token 前失败、中途失败、停止与 chunk 同时到达、断线、重连、快照慢于事件、删除后的迟到事件。
9. 角色自然任务：闲聊、技术解释、数学推导、代码请求、剧情推进、请求看场景/表情/CG、自然选择分支。

## 10. 完成定义

矩阵完成需同时满足：

1. 所有 U/E/C/L 可在当前环境执行的项目均有逐项结果和证据链接。
2. 发现的功能缺陷先修复，再从最窄测试扩展到全量回归；不能只写报告绕过。
3. 所有 E2E 均后台运行；Codex 标签页仅用于用户要求的人工 WebDev 验收与截图。
4. 所有截图经人工查看，视觉差异有结论；不能仅依赖快照测试返回码。
5. 最新 clean commit 上重新执行 lint、typecheck、unit、coverage、build、Web required E2E、Electron E2E、recovery 和 live-model。
6. D/N/R 类如环境不足，逐项写 `BLOCKED`、缺失条件、影响和负责的后续验收，不得计入通过率。
7. 最终报告给出每个矩阵 ID 的 `PASS/FAIL/BLOCKED/NOT RUN`、证据、发现、修复提交与复测结果，并分别给出：主对话 WebDev 结论、Desktop 结论、真实设备/辅助技术结论、公开发布结论。

## 11. 审核决策点

请重点确认以下预期是否符合产品意图，审核后再冻结矩阵：

1. 用户主动发送时，即使之前正在阅读上文，也恢复自动跟随到底部。
2. 每个会话的未发送草稿按会话隔离并在来回切换时保留。
3. 中途停止或失败时保留已流出的 assistant 文本，并明确标记为未完整完成。
4. 长回复加入“复制全文”和轻量顶部/底部导航，但不拆分 Pi 消息。
5. 每个代码块加入独立复制操作，复制原始源码。
6. 远程 Markdown 图片始终不加载；角色图片只能走 `host_media`。
7. settled handoff 完全不做二次入场动画；stop/error/edit/regenerate 只做克制的状态过渡。
8. 真实模型剧情测试允许模型判断是否需要 Media/Choices；不调用工具本身不算失败，只有语境明显需要且模型表现不合理才由人工判定失败。

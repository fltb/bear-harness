## 实现与所有权

- Host 持有安装级 Canon embedding 句柄，读取既有系统设置及凭据，等待模型就绪。同一 Host 的多个角色共用这个模型句柄；文本块、向量及元数据仍在各自角色数据库。
- Canon 不再从 `memoryRuntime` 取得 embedding，不启动 TDAI，也不要求角色同意自动关系记忆。TDAI 自己的记忆服务与同意边界保留。
- `host_canon`、Canon 搜索和自动上下文使用同一混合检索入口。启用 embedding 时，检索前完成待处理索引；未配置时文字查询继续可用。配置了服务却索引失败，会明确报错，不能以空结果冒充成功。
- 按角色串行处理索引请求；服务失败可在下一次查询重试；源文件在 embedding 期间被删除或替换时，不回写旧内容；关闭角色时等待索引任务退出。设置变化会重置模型句柄并为已打开角色重新索引。
- 向量候选只加载命中的行，不再读出当前角色全部正文。模型/维度/Canon 编码策略指纹变化会清空并重建该角色的索引。
- 单独标题不构成资料证据，分块不再为它建立独立向量；包索引指纹随分块规则更新。
- 本地适配器原有单次 512 字符裁切仍在；Canon 把长文本分成 480 字符片段，长度加权平均后归一化，覆盖全部正文。EmbeddingGemma 区分查询和文档的前缀，按 [Google 官方格式](https://ai.google.dev/gemma/docs/embeddinggemma/model_card#prompt-instructions) 加入。自定义其他本地模型不套用 Gemma 前缀。
- 本地模型释放修复：等待 embedding context 释放后再释放模型，去重并发关闭。实测最初退出时触发原生资源断言，修复后正常退出。

未改 Pi 的消息、会话执行状态、工具结果存储或记忆采集规则。没有引入旧数据兼容层。

# Canon 与关系记忆共享 embedding · 2026-09-30

已将原先 Canon 专用模型句柄改为 Host 统一持有的 SharedEmbeddingRuntime。Canon、当前角色的 TDAI，以及同一 Host 中其他角色的 TDAI，借用同一个已就绪的模型实例；文件和系统设置本来就是共用的，本次消除的是重复创建运行实例。

## 所有权与行为

- Host 唯一负责正常运行时 embedding provider 的创建、预热、配置重置与释放。消费者拿到的接口没有释放权限；关闭一个角色的记忆或关闭其数据库不会释放其他消费者正在使用的模型。
- 并发首次使用去重；本地单条、批量与 Canon 分段请求共用串行队列，避免同时操作同一个原生 embedding context。某次请求失败不阻塞后续请求。
- 修改配置时先停止已有角色记忆消费者，再等待共享模型已接收的工作完成并释放；下次使用重新加载。旧消费者不能继续使用已释放实例。Host 退出在角色资源关闭后释放模型。
- Canon 的查询/文档前缀和长段落处理仍属于 Canon；TDAI 原输入策略与模型指纹保持不变。索引继续分开，每个角色仍有独立数据库，不因共享模型混合数据或新增重建要求。
- Canon 不要求关系记忆开关打开，也不会启动记忆采集。角色关闭关系记忆仍能查询 Canon。
- TDAI 核心新增显式 provider 注入；Host 始终注入共享实例。TDAI 单独使用时仍能自行创建服务；注入路径返回空值时不会另建模型来回退。

# i18n

## 文案所有权

`@bear-harness/i18n` 管理产品界面文案，支持 `zh-CN`、`zh-TW` 和 `en`。角色的名字、greeting、first meeting、scene、expression、work labels 和故事文本属于角色包，不复制进产品 catalog。

源码位于 [`packages/i18n/src`](../../packages/i18n/src)：简体中文是主要编辑源，英文人工维护，繁体中文由仓库流程生成并通过 key parity 测试。

## API 与运行时

UI 使用类型化 translation key 和受控 interpolation。locale 是产品偏好，切换语言不能重建 store、关闭 Session、改变 active conversation 或重置 onboarding。角色包可以声明自己的内容语言，但不改变产品安全错误和系统设置文案的来源。

来自 Host 的 error kind 先映射为产品文案；不要直接把内部异常、路径或 provider secret 渲染给用户。角色包文案经过 schema 验证后以 text 呈现，不作为 HTML。

## 贡献流程

1. 在 `locales/types.ts` 增加 typed key；
2. 更新 `zh-CN.ts` 与 `en.ts`；
3. 运行繁体生成流程；
4. 跑 catalog parity、interpolation 与 locale lifecycle 测试；
5. 检查新文案究竟属于产品还是角色。

```sh
npm run typecheck --workspace @bear-harness/i18n
npm run test:unit --workspace @bear-harness/i18n
```
